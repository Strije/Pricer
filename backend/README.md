# Pricer backend

Этап 0 миграции: ядро без Qt, перенесённое из десктопного приложения.

- `core/` — 35 модулей десктопа без изменения логики (поставщики, нормализация, заказы, кроссы,
  бренды, чтение файлов) и `pricing.py`, вынесенный из `markup_editor.py`.
  Модули пока плоские (`import provider_adapter`), пакетная структура будет на следующем шаге.
- `integrations/` — интеграция с 1С через OData: клиент с идемпотентным созданием документов,
  сборка документов из заказа и очередь выгрузки (outbox).
- `tests/` — pytest. Запуск: `pip install -e ".[dev]" && python -m pytest`.

Секреты (`settings.json`, ключи поставщиков) в репозиторий не добавляются, см. `.gitignore`.
Не перенесено: `one_c_provider.py` (COM, только Windows), все модули с PyQt6, `main.py`.
